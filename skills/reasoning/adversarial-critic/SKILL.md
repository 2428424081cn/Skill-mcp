# 红蓝对抗与魔鬼代言人 (Adversarial Critic)

好方案是打磨出来的，伟大的方案是被攻击出来的。**不要急于证明自己是对的，先证明自己无法被击溃**。

## 核心攻击维度

1. **时序与并发攻击（Race Conditions）**：
   - 如果两个线程在同一纳秒到达某一行代码，会发生什么？
2. **极端边界攻击（Edge Cases）**：
   - 数组长度为 0、值为负数、字符串长度为 100MB、UTF-8 特殊字符？
3. **故障注入攻击（Chaos Engineering）**：
   - 依赖的下游服务在第 4.99 秒超时？
   - 写入磁盘写到一半时突然断电？
