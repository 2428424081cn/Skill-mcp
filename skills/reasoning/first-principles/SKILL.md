# 第一性原理思考指南 (First Principles Reasoning)

第一性原理是亚里士多德与马斯克推崇的究极思考范式：**把事物拆解到最基础的事实公理，然后从底层往上推导**。

## 三步推导法

### 第一步：识别并质疑所有“理所当然”的假设
列出所有传统做法中的习惯性假设：
- *“行业里大家都用 Redis 做这事”* ➔ 为什么？是必须用，还是只是图省事？
- *“这个查询必须在 1 秒内完成”* ➔ 真实物理限制是网络延迟还是序列化？

### 第二步：提取不可动摇的基础事实（Ground Truths / Axioms）
- 计算机科学硬约束：时间复杂度、内存容量、光速网络 RTT、磁盘顺序读写与随机读写吞吐差异。

### 第三步：从底层事实自底向上重新构建解决方案
不参照任何现有框架，仅用基础积木搭建最简、最快、最本质的解法。
