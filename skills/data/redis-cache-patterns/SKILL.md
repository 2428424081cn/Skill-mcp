# Redis 高并发缓存设计模式指南

## 三大缓存灾难防御
1. **缓存穿透**：查询不存在的数据导致请求全部穿透到 DB -> 使用布隆过滤器（BloomFilter）或空值缓存（带短 TTL）。
2. **缓存雪崩**：大量缓存集中在同一时刻过期 -> 基础 TTL 叠加随机抖动值（如 `baseTTL + random(0, 300)`）。
3. **缓存击穿**：热点 Key 突然失效时高并发打入 DB -> 使用互斥锁（Mutex）控制仅一个线程回源更新。
